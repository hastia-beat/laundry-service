# LaundryKu

PHP + MySQLi + Bootstrap + JavaScript. Dijalankan di XAMPP.

run
1. Salin folder `laundryku/` ke `htdocs`.
2. phpMyAdmin → Import `database/laundryku.sql`.
3. Buka `http://localhost/laundryku/setup_demo.php` "sekali saja dan lansung hapus foldernya bro -_-"
4. Buka `http://localhost/laundryku/`.
